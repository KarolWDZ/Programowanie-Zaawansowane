# my_awesome_lib

`my_awesome_lib` to prosta biblioteka w języku Python, zawierająca funkcje do:

- pracy z danymi (`data_utils`)
- wykonywania prostych obliczeń matematycznych (`math_tools`)
- przetwarzania tekstu (`text_processing`)

Projekt został przygotowany jako ćwiczenie z tworzenia własnych pakietów Python, organizacji kodu, dokumentacji oraz testów jednostkowych.
